# 📊 Sales Dashboard Project

## 📌 Project Overview
This project is an interactive Sales Dashboard built to analyze and visualize sales performance data.  
It helps in tracking revenue, profit, quantity sold, and regional performance.

The dashboard provides insights that help businesses make data-driven decisions.

---

## 🎯 Objectives
- Analyze total sales and profit
- Identify top-performing products
- Track sales by region
- Monitor monthly sales trends
- Compare category-wise performance

---

## 📂 Dataset Information
- File Name: salesdata.csv
- Contains sales transaction data
- Includes columns like:
  - Order Date
  - Region
  - Product Category
  - Sales
  - Profit
  - Quantity

---

## 📊 Dashboard Features
- KPI Cards (Total Sales, Total Profit, Total Orders)
- Sales Trend (Monthly/Yearly)
- Region-wise Sales Analysis
- Category-wise Performance
- Top Products Visualization
- Interactive Filters
